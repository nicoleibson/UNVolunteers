SECCIÓN 1: VISIÓN GENERAL DEL PROYECTO
=======================================

Project Lifeline Core es un sistema de simulación de comunicaciones de
emergencia diseñado para Voluntarios de las Naciones Unidas (UNV) que operan
en escenarios de respuesta a desastres donde la infraestructura normal
(torres celulares, internet) ha sido destruida o está fuera de servicio.

El proyecto tiene dos componentes principales:

1. MÓDULO DE RADIO RF (carpeta radio/)
   - Implementa una pila completa de comunicaciones por radiofrecuencia
   - Incluye: LoRa mesh, APRS, SDR, gestión de frecuencias, codificación de paquetes
   - Todo en JavaScript, como simulación/referencia

2. SIMULADOR VISUAL AMRF (carpeta simulation/simulation/)
   - Aplicación web interactiva para entrenamiento y planificación
   - Dos versiones: base (v1.2) e integrada con RF (v2.0)
   - Dashboard con canvas HTML5, visualización en tiempo real

ARQUITECTURA DE 3 CAPAS:
- Capa Zona de Desastre: BLE + LoRa + APRS entre nodos
- Capa Gateway/Scout: LoRa Gateway + APRS Igate + SDR Receiver
- Capa Centro de Comando: Satélite + HF Radio + Internet Backup

================================================================================
                         COMMUNICATION LAYERS
================================================================================

LAYER 1: BLE MESH (0-100m)
- Device-to-device communication
- Low power, short range
- For trapped victims nearby

LAYER 2: LORA MESH (100m-15km)
- Node-to-gateway communication
- Long range, low power
- For deep rubble penetration

LAYER 3: APRS/VHF (1-50km)
- GPS tracking and messaging
- Real-time position reporting
- For rescue team coordination

LAYER 4: HF RADIO (50-1000km)
- Long range command & control
- Satellite backup
- For regional coordination

                         LEGAL NOTES
================================================================================

- ISM bands (433/868/915 MHz): License-free for low power
- VHF/UHF Amateur: Requires amateur radio license
- HF: Requires license for transmit
- Emergency use: May have exceptions under disaster declarations
- ELT/EPIRB: Licensed for emergency only (406 MHz)

WHAT'S NEW IN v2.0:
═══════════════════

1. LORA MESH NETWORK (Panel 11)
   - Frequency: US915 (915 MHz ISM band)
   - Features: Mesh routing, multi-hop relay, adaptive spreading factor
   - Real-time waveform visualization
   - RSSI/SNR monitoring
   - Automatic node discovery and beaconing

2. APRS PROTOCOL (Panel 12)
   - Frequency: 144.390 MHz (VHF 2m Amateur)
   - Features: Position tracking, message relay, digipeater
   - Support for APRS objects and IS gateway
   - Real-time packet logging

3. SDR RECEIVER (Panel 13)
   - Frequency: 433 MHz ISM band (configurable)
   - Features: Signal detection, spectrum analysis
   - Waterfall display visualization
   - Multi-signal simultaneous decoding

4. FREQUENCY ALLOCATION (Panel 14)
   - Visual display of all active frequency bands
   - Status indicators for each band
   - ISM 915 (LoRa), VHF 2m (APRS), ISM 433 (SDR), HF 7MHz (planned)

HOW TO RUN:
═══════════
1. Navigate to the simulation directory:
   cd /storage/emulated/0/Documents/UNVolunteers/simulation/simulation

2. Start the HTTP server:
   node server.js

3. Open browser to:
   http://localhost:8000/index_integrated.html

4. Click "⚡ TRIGGER P-WAVE" to activate all RF systems

SIMULATION FLOW:
════════════════
1. DORMANT → All RF systems offline
2. TRIGGER P-WAVE → Cell Broadcast received
3. RF Systems Init:
   - LoRa mesh network initialized with 3 nodes
   - APRS tracker activated with position beacons
   - SDR receiver starts scanning for signals
4. Active Monitoring:
   - LoRa: Periodic beacons every 5s
   - APRS: Position updates every 30s
   - SDR: Continuous signal scanning
5. Emergency:
   - SOS button transmits on all frequencies
   - Multi-protocol redundant messaging

SECCIÓN 4: RESUMEN DE ARQUITECTURA GENERAL
===========================================

Los módulos de radio/ NO se importan directamente como módulos ES en el
simulador. Su lógica está re-implementada/embebida dentro de app_integrated.js.
Los archivos en radio/ funcionan como módulos de referencia del stack RF.

Flujo de datos del sistema:
  SDR Receiver → Packet Encoder → APRS Protocol / LoRa Mesh
                      ↑                     ↑
              Frequency Manager ────────────┘

Capas de comunicación:
  Layer 1: BLE Mesh (0-100m) — Comunicación dispositivo a dispositivo
  Layer 2: LoRa Mesh (100m-15km) — Largo alcance, bajo consumo
  Layer 3: APRS/VHF (1-50km) — Tracking GPS y mensajería
  Layer 4: HF Radio (50-1000km) — Comando y control de largo alcance
